Wireshark HTTP Traffic Analysis

Project Overview

This project focuses on capturing and analyzing HTTP network traffic using Wireshark in Kali Linux.

Objective

To understand HTTP communication, analyze HTTP requests and responses, and identify different HTTP status codes.

Tools Used

- Kali Linux
- Wireshark
- Oracle VirtualBox
- Firefox Browser

Practical Tasks Performed

1. Captured HTTP network traffic.
2. Analyzed HTTP GET requests.
3. Identified HTTP 200 OK responses.
4. Observed HTTP 301 Moved Permanently redirects.
5. Used Follow HTTP Stream to inspect HTTP communication.
6. Examined TCP packet details.

Key Learnings

- HTTP GET requests
- HTTP response codes
- TCP communication
- Packet inspection
- Client-server communication
